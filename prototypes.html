01 · Product prioritization

DateLight

Live

The app goal was deliberately narrow: turn location, timing, mood, budget, and distance into a short list of usable date ideas in under a minute.

Decision
Plan the work as usable increments and hold the full visual-polish pass until the core search, radius, and AI-curation flow worked end to end.
Shipped result
A live mobile-ready flow with Places data, preference filters, AI-curated recommendations, and a Vercel proxy that keeps the Gemini credential out of client code.
Deferred
The planned Phase 4 polish backlog — richer loading states, micro-interactions, and a mobile results sheet — remained outside the core release.
Next release
Complete the bounded Phase 4 UX-polish backlog without reopening the app's core scope.
Evidence
The five-phase milestone plan states “ship each phase as a usable increment”; the proxy commit and reusable Vercel guide document the public-release boundary.

02 · Creative direction & iteration

Ultraviolette

Live Beta

A single visual promise organized the game: every run should transform a grey, depleted city into something colorful and joyful.

Decision
Use a web-native Three.js stack instead of a full game engine so the runner could stay lightweight, deploy directly to the browser, and own its rendering pipeline.
Shipped result
A playable browser runner with pooled world objects, lane movement, collision tuning, and a custom GPU shader that spreads color through the city.
Deferred
The custom GLB asset pass and horn-drill polish were explicitly moved to optional Phase 7 rather than blocking the beta.
Next release
Expand the single-city run into the documented multi-zone structure: suburbs, city, and industrial.
Evidence
The technical brief records the engine tradeoff; the phased build guide and code preserve object-pooling, collision, and performance rules.

03 · Scope discipline

Hello Whirled

Live

Hello Whirled is intentionally a toy, not a feature-heavy game: discover a world, greet it, spin it, and generate another.

Decision
Ship the game standalone and full-screen rather than carrying tabs, ads UI, and platform navigation into the public experience.
Shipped result
A game-only React and Vite wrapper that preserves the working vanilla JavaScript planet core and exposes only its progression and interaction controls.
Deferred
Tabs, ads, and platform chrome stayed out of the standalone release.
Next release
Convert the remaining game modules to React and TypeScript gradually, without rewriting the working game core all at once.
Evidence
The migration and final-setup documents explicitly call for “just your game”; the standalone lifecycle stub and full-screen container implement that boundary.

Direction & handoff

Work another artist can pick up

These sample briefs show how I turn direction into an executable handoff: a defined starting state, bounded creative freedom, technical constraints, named deliverables, and review criteria. These are direction samples — I'm showing the brief, not claiming the finished asset.

Kitchen Set Dressing 3D handoff Blender 3-hour scope Compose a complete game kitchen from 34 provided assets without changing the asset library.

Starting state

A Blender scene with 34 named assets organized into Architecture, Furnishings, and Objects. No scene arrangement has been done.

Guardrails

Placement and composition only. Do not change geometry, materials, or UVs. Lighting and final rendering are outside scope.

Deliverables & review

  • One organized, packed Blender file with transforms applied
  • Orthographic, top-down, and wireframe viewport captures
  • Review for spatial clarity, intentional coverage, and prototype readiness
Apparel Mockups 2D handoff GIMP 5-hour scope Build a cohesive six-piece merch line for a punk-influenced fantasy sports brand.

Starting state

Six flat garment drawings plus the approved brand logo. Line art must remain preserved above fills and graphics.

Guardrails

Streetwear and skate influence, not team-store merchandise. Keep one tight palette and make placement appropriate to each garment.

Deliverables & review

  • Organized working files for tee, hoodie, cap, beanie, crewneck, and cardigan
  • Six clean PNG concept exports
  • Review for logo clarity, family cohesion, and wearability
